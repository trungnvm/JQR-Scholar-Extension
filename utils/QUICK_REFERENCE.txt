  → Verify OpenAlex API is accessible
  → Use --email flag for better rate limits

Impact factor fails:
  → Check SJR CSV path
  → Try without --sjr-csv flag
  → Will fallback to OpenAlex metrics

Conversion fails:
  → Verify CSV files exist in data/processed/
  → Check CSV has required columns (issn, name)
