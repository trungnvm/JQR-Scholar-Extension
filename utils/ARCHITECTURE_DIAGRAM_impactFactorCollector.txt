CLASS HIERARCHY
===============

ImpactFactorCollector
│
├── Contains: SJRDataLoader
│   │
│   ├── Data: pandas DataFrame (sjr_data)
│   ├── Index: dict[str, int] (issn_index)
│   │
│   └── Methods:
│       ├── load_sjr_csv(file_path) → bool
│       ├── get_impact_metrics(issn) → dict
│       ├── _normalize_issn(issn) → str
│       └── _build_issn_index() → None
│
└── Contains: OpenAlexMetrics
    │
    ├── Data: requests.Session (session)
    ├── Config: rate_limit_delay = 0.1
    │
    └── Methods:
        ├── get_citation_metrics(issn) → dict
        ├── get_2yr_mean_citedness(issn) → float
        ├── batch_get_metrics(issn_list) → dict
        └── _make_request(url, params) → dict

WORKFLOW DIAGRAM
================

1. Data Collection
   ─────────────────

   User ISSNs → batch_collect() → For each ISSN:
                                   ├─ Try SJR
                                   ├─ Try OpenAlex
                                   └─ Aggregate results

2. Data Export
   ────────────

   Results dict → export_to_js() → JavaScript file
                  export_to_csv() → CSV file

3. Extension Integration
   ──────────────────────

   JavaScript file → <script src="..."> → Extension loads
                                         → Display in UI

API RATE LIMITING
=================

┌────────────────────┐
│ API Request Queue  │
└────────┬───────────┘
         │
         ▼
   ┌──────────────┐
   │Rate Limiter  │
   │(0.1s delay)  │

          │
          ▼
   ┌────────────┐
   │Make Request│
   └──────┬─────┘
          │
          ├─── Success (200) ────────► Parse & Return
          │
          ├─── Rate Limited (429) ───► Retry with Backoff
          │
          └─── Error (5xx) ──────────► Retry (max 5x)

PERFORMANCE CHARACTERISTICS
===========================

Operation                 Complexity    Time
─────────────────────────────────────────────
SJR ISSN Lookup          O(1)          < 1ms
OpenAlex API Call        O(1)          100-500ms
Batch Collect (n items)  O(n)          n × avg_time
CSV Load (n rows)        O(n)          2-5s (10k rows)
JavaScript Export        O(n)          < 100ms (1k items)


MEMORY USAGE
============

Component              Memory Usage
────────────────────────────────────
SJR DataFrame         ~10-50 MB (depends on data size)
ISSN Index            ~1-5 MB
OpenAlex Session      ~1 MB
Results Dictionary    ~100 KB per 1000 journals
Export Files          ~50 KB per 1000 journals
