Kiểm tra chất lượng tạp chí khoa học ngay trên Google Scholar

Manifest V3 Chrome Firefox v1.0
English · Tiếng Việt

📚 Giới thiệu

JQR là extension giúp bạn đánh giá nhanh chất lượng tạp chí khi tìm kiếm trên Google Scholar. Không cần mở tab khác — ranking hiển thị trực tiếp bên cạnh mỗi kết quả tìm kiếm, với badge màu sắc trực quan.

🚀 Cài đặt

Tải extension — nhấn nút Code → Download ZIP trên GitHub, rồi giải nén
Mở trang extension — gõ vào thanh địa chỉ:
  • Chrome: chrome://extensions/
  • Edge: edge://extensions/
  • Brave: brave://extensions/
Bật Developer mode — toggle ở góc trên bên phải trang
Nhấn "Load unpacked" — chọn thư mục JQR-Scholar-Extension (chứa file manifest.json)
Xong! Icon JQR sẽ xuất hiện trên thanh công cụ
Tải extension về máy (giống Chrome ở trên)
Mở Firefox, gõ: about:debugging#/runtime/this-firefox
Nhấn "Load Temporary Add-on..." → chọn file manifest.json
Vào cài đặt addon → cấp quyền cho Google Scholar (vd: scholar.google.com.vn)
⚠ Cài tạm thời trên Firefox sẽ mất khi restart. Để cài vĩnh viễn: Firefox Add-ons
Clone repo: 
git clone https://github.com/trungnvm/JQR-Scholar-Extension.git
Mở thư mục JQR-Scholar-Extension và load vào trình duyệt theo hướng dẫn Chrome hoặc Firefox ở tab bên cạnh

📖 Cách sử dụng

1

Mở Google Scholar

Truy cập scholar.google.com và search bình thường

2

Xem ranking

Badge xếp hạng xuất hiện tự động bên cạnh kết quả

3

Hover & Click

Di chuột xem chi tiết, nhấn để mở DOI bài báo

4

Tùy chỉnh

Nhấn icon JQR trên toolbar để cấu hình

💡 Nhấn "Advanced Settings" trong popup để chọn cụ thể ranking nào muốn hiển thị
