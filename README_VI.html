JQR - Kiểm Tra Chất Lượng Tạp Chí

Hiển thị xếp hạng tạp chí ngay trên Google Scholar

Manifest V3 Chrome Firefox v1.0
🇬🇧 English · 🇻🇳 Tiếng Việt

📌 Giới thiệu

JQR là extension trình duyệt giúp bạn kiểm tra nhanh chất lượng tạp chí khoa học ngay trên kết quả tìm kiếm Google Scholar — không cần mở tab khác hay tra cứu thủ công.

Extension sẽ tự động hiển thị các badge xếp hạng (SJR, Impact Factor, H-Index...) bên cạnh mỗi kết quả, với màu sắc trực quan từ xanh (chất lượng cao) đến đỏ (chất lượng thấp).

✨ Tính năng chính

  • 📊 15+ hệ thống xếp hạng — SJR, Impact Factor, H-Index, VHB, ABDC, AJG, CORE, CCF, CNRS, FNEGE, FT50, HCERES, BFI, SNIP, CiteScore
  • 🎨 Badge màu sắc — Xanh lá = chất lượng cao, Đỏ = chất lượng thấp
  • 🔍 Tìm kiếm tạp chí — Tra cứu ranking của bất kỳ tạp chí nào từ popup
  • 🏷️ Phân loại lĩnh vực — Tự động nhận diện lĩnh vực nghiên cứu
  • 🖱️ Hover xem chi tiết — Di chuột lên badge để xem H-Index, tên tạp chí
  • 🔗 Click vào DOI — Nhấn badge để mở bài báo gốc
  • ⚙️ Tùy chỉnh — Bật/tắt từng ranking theo nhu cầu

🚀 Hướng dẫn cài đặt

Cài trên Chrome / Edge / Brave

  1. Tải extension về máy:
    • Nhấn nút Code → Download ZIP trên GitHub
    • Hoặc clone qua terminal: 
      git clone https://github.com/trungnvm/JQR-Scholar-Extension.git
  2. Giải nén file ZIP (nếu tải ZIP)
  3. Mở trang quản lý extension:
    • Chrome: gõ chrome://extensions/
    • Edge: gõ edge://extensions/
    • Brave: gõ brave://extensions/
  4. Bật Developer mode (Chế độ nhà phát triển) — toggle ở góc trên bên phải
  5. Nhấn "Load unpacked" (Tải tiện ích đã giải nén)
  6. Chọn thư mục JQR-Scholar-Extension (thư mục chứa file manifest.json)
  7. ✅ Extension sẽ xuất hiện trên thanh công cụ!

Cài trên Firefox

  1. Tải extension về máy (như trên)
  2. Mở Firefox, gõ vào thanh địa chỉ: about:debugging#/runtime/this-firefox
  3. Nhấn "Load Temporary Add-on..."
  4. Chọn file manifest.json trong thư mục JQR-Scholar-Extension
  5. Vào cài đặt addon → cấp quyền cho Google Scholar (vd: https://scholar.google.com.vn)
Cài tạm thời trên Firefox sẽ mất khi restart. Để cài vĩnh viễn, tải từ Firefox Add-ons.

📖 Hướng dẫn sử dụng

  1. Mở Google Scholar và tìm kiếm bình thường
  2. Các badge xếp hạng sẽ xuất hiện tự động bên cạnh mỗi kết quả
  3. Di chuột lên badge → xem chi tiết (H-Index, tên tạp chí)
  4. Nhấn vào badge → mở DOI bài báo
  5. Nhấn icon JQR trên toolbar để bật/tắt hoặc tìm kiếm tạp chí
  6. Nhấn "Advanced Settings" để chọn ranking muốn hiển thị

📝 Ghi chú

  • Extension hoạt động trên tất cả domain Google Scholar (scholar.google.com, .com.vn, .co.uk, ...)
  • Dữ liệu ranking được lưu offline trong extension, không cần internet để tra cứu
  • Nếu tạp chí không tìm thấy trong database offline, extension sẽ tra qua Crossref API
